# 2026.0802 — Safer agents and a Rust-first shell

This release makes the macOS environment safer by default, more reproducible
across machines, and deliberately Rust-first for interactive CLI work.

## Highlights

### Rust-first interactive CLI

- Restored visible Fish abbreviations for `cat → bat`, `grep → rg`,
  `ls → eza`, `find → fd`, and `du → dust` without changing script semantics.
- Added mature, actively maintained Rust tools from Homebrew core:
  `sd`, `procs`, `bottom`, `xh`, `ripgrep-all`, `hexyl`, and `gping`.
- Added interactive mappings for `sed → sd`, `ps → procs`, `top → btm`,
  `ping → gping`, plus explicit `http → xh`, `hex → hexyl`, and
  `bench → hyperfine` commands.
- Kept `rga` explicit for PDFs, archives, Office documents, and other rich
  formats instead of replacing normal `rg` searches.
- Recorded a durable selection policy: prefer non-archived, recently active,
  substantially adopted Rust projects with Homebrew core packages and a
  concrete non-overlapping workflow benefit.

### Safer defaults

- `c` / `cc` now start Claude Code with normal permission checks; the bypass is
  explicitly named `cunsafe`.
- `cx` now starts Codex with its normal sandbox and approval behavior; the full
  bypass is explicitly named `cxunsafe`.
- `dsp` keeps Docker's confirmation prompt; forced all-resource cleanup moved
  to `dspunsafe`.
- Go no longer disables checksum verification or forces direct downloads.
  Retired shared values are cleared while legitimate inherited corporate proxy
  settings remain intact.
- Ghostty now asks before terminal applications read the clipboard.

### Reproducibility and local integration

- Added config-required and validation-required tools to `Brewfile`, including
  Go, jj, rtk, Docker/Compose, kubectl, SOPS, ShellCheck, StyLua, git-secrets,
  the Ghostty font, and the selected Rust CLI set.
- Normalized Go tooling to the standard `$HOME/go` workspace while leaving the
  old `$HOME/gopath` directory untouched for recovery.
- Switched repo-managed Fish PATH additions to process-local `--path` updates
  and removed their stale universal-variable copies from the local machine.
- Pinned Sponge to `1.1.0`, matching the repo compatibility override.
- Pinned Fisher `4.4.8`; first-install bootstrap uses a reviewed commit and a
  SHA-256 check before sourcing downloaded code.
- Linked Homebrew's Docker Compose plugin into Docker's user plugin directory
  without taking ownership of credential-bearing `~/.docker/config.json`.

### Git, linking, and workflow safety

- Replaced the destructive `power_pull` hard reset with an argument-free,
  fast-forward-only pull that refuses detached HEAD and divergent history.
- Added `pull.ff=only`, fetch pruning, and `main` as Git's initial branch.
- `scripts/link.sh` now leaves correct links untouched, backs up conflicting
  files and unrelated symlinks, reports the backup location, and cleans stale
  managed Fish function links.
- Warp's merged-branch cleanup now works from Fish by invoking a guarded POSIX
  shell, refuses detached HEAD, protects common mainline branches, and stops on
  deletion failure.

### Agent, rule, and skill alignment

- Added same-named Codex counterparts for the dotfiles auditor, planner, memory
  optimizer, and incident responder.
- Aligned the Claude and Codex incident responders around an explicit
  read-oriented tool surface and evidence-first mutation guidance.
- Extended the agent audit to validate Claude/Codex persona parity, internal
  names, descriptions, TOML syntax, skill frontmatter, invocation policy,
  symlinks, secrets, and generated-file drift.
- Updated `add-config`, `add-package`, security, and authoring guidance with
  guarded aliases, effective-config checks, Rust-first selection criteria,
  command compatibility, and Brewfile source-of-truth rules.
- Expanded the environment auditor to check effective runtime behavior rather
  than accepting parser success alone.

### Editor and terminal correctness

- TypeScript and JavaScript formatting now selects `deno_fmt` only under a
  `deno.json` / `deno.jsonc` root and otherwise uses Prettier.
- Updated Ghostty's scrollback key to the current
  `scrollback-limit-bytes` name.

## Behavior changes

- Standard command replacements are Fish abbreviations, not functions. They
  visibly expand while typing and do not affect scripts. Use `command grep`,
  `command ls`, and similar forms when the native command is wanted
  interactively.
- `power_pull` no longer accepts arguments and never performs a hard reset.
- Machine-specific `~/.config/fish/local.fish` is now sourced for interactive
  and non-interactive Fish. UI-only statements inside it must guard themselves
  with `status is-interactive`.

## Upgrade

```bash
brew bundle --file Brewfile
./scripts/link.sh
fish scripts/install-fish-plugins.fish
exec fish
```

## Verification

The release is checked with Fish and Bash syntax validation, ShellCheck,
StyLua, Neovim headless startup, Conform formatter-selection smoke tests,
Ghostty config validation, Brew Bundle, Docker Compose, Claude Code doctor,
Codex strict config and doctor, the repository agent audit, secret scanning,
an independent Claude Code peer review, and focused regression checks for
command abbreviations and safe Git helpers. The Warp cleanup check executes the
embedded workflow against a scratch repository containing merged and unmerged
branches instead of relying on YAML or shell syntax alone.

## Known local follow-ups

These are not introduced by this release and are intentionally not repaired
automatically:

- Homebrew reports stale `libtiff` / `webp` dependency metadata and several
  legacy or disabled packages that require explicit uninstall/reinstall choices.
- Codex doctor reports historical rollout storage and stale thread references;
  the supported doctor command provides diagnostics but no cleanup action.
- Ghostty remains on the intentional `ghostty@tip` channel.
