# Neovim and LazyVim configuration

For changes under this repository's `nvim/`, read
[nvim/AGENTS.md](../../../../nvim/AGENTS.md) for editing boundaries, compatibility
checks, keymap ownership, and test isolation. `nvim/CLAUDE.md` is a symlink to
that file, so Claude and Codex use the same area-specific instructions.

Read the relevant sections of [nvim/README.md](../../../../nvim/README.md) for
current behavior and executable validation commands. Keep Neovim-specific rules
in `nvim/AGENTS.md` rather than duplicating them in this reference.
