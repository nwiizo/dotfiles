# Explain the Incident and the Next Change

Use the team's template and publication process.
Reconcile time zones, event times, impact, and duration.
Keep verified facts, estimates, hypotheses, and unknowns distinguishable.

Separate trigger, failure mechanism, contributing conditions, and recovery.
Explain decisions using the information available at the time.
Avoid attributing motives or forcing a single root cause.

Tie each follow-up action to an observed failure or response gap, with owner,
completion evidence, and date when known.
Distinguish restored service from permanent remediation and verified data integrity.

Return the requested draft or review with supporting evidence.
Keep private records in the authorized workspace; writing does not authorize
posting messages or creating external tickets.
