# Resolve Implementation Uncertainty

依頼・コード・既存の決定から、実現する動作と未決の前提を読み取る。
調べて分かることは確かめ、利用者の目的や優先度が必要な選択だけ質問する。
回答に依存しない作業は続ける。

最小実装では必要な入力から結果までを通す最も単純な案を選ぶ。
必要な機能を落とさず、成功する操作と重要な失敗例の確認方法を決める。
実装の選択は [nwiizo-coding-style](../SKILL.md) を使う。
前提が解決したら編集と検証へ進む。

参考: [Karpathyの観察](https://x.com/karpathy/status/2015883857489522876)、
[andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)。
