# Resolve Review Findings

Read the specified review and actual implementation.
For each finding, identify the requirement, triggering state or input, and
observable consequence. Inspect or test that path before accepting the claim.

Consolidate duplicates. Distinguish a demonstrated defect, a misread requirement,
an accepted tradeoff, and an unsupported concern.
Reviewer confidence, majority agreement, or repeated identical reviews do not
settle conflicting evidence.

Apply valid changes within scope and preserve intentional behavior.
Run relevant verification after the edit.
Keep finding identifiers when available and report applied, declined, and
unresolved findings with concrete reasons.
